# AgentOps

**给传统 RPA 加一层 AI 决策。** 不替代影刀、实在智能、八爪鱼、APath、弘玑，而是在它们之上做一个统一的运维层：接入建议、根因分析、成本优化、异常检测。每条 AI 建议都可追溯、可采纳、可驳回。

> 演示项目：数据为本地 mock，页面所有指标均标注「演示口径」，非生产实测。

---

## 为什么做这个

同时使用多个 RPA 平台的中小企业运维团队，面对三个结构性问题：

1. **多平台割裂**——五个平台各自为政，没有统一视图，巡检靠人肉切换后台；
2. **故障发现滞后**——报错能看到，但「流程该跑没跑」往往要等业务侧投诉才暴露；
3. **成本黑盒**——RPA 投入与产出没有量化口径，回答不了「这套自动化到底值不值」。

## 定位：只做运维层，不做生成层

生成层是平台厂商的主场——它们掌握执行引擎与动作库，做得比第三方更近、更好。而跨平台统一运维是厂商天然不会做的真空地带，没有厂商有动机替竞品做监控。因此 AgentOps 用 Adapter 模式抽象平台差异，只在这一层上做产品。

## 信息架构

| 路由 | 模块 | 做什么 |
| --- | --- | --- |
| `/` | 总览 | 全局健康度、待处理事项、模块入口 |
| `/agents` | M1 流程接入 | 流程列表与 AI 平台适配建议 |
| `/agents/new` | M1 流程接入 | 新建流程，AI 推荐目标平台与适配器 |
| `/agents/[id]` | M1 流程接入 | 流程详情、执行配置与运行记录 |
| `/security` | 安全与权限 | 凭据、角色、审计 |
| `/costs` | M5 成本优化 | 每个流程的月度净价值与 ROI |
| `/monitoring` | M2 监控追踪 | Health grid + 24h Gantt + 执行列表 + 根因分析 |
| `/ai-cockpit` | AI 决策痕迹 | 四象限建议、采纳/驳回、能力边界声明 |

## 三个关键产品决策

### 决策一：做运维层，不做生成层

- **决策**：不做 RPA 流程生成，只做平台之上的统一运维与 AI 决策。
- **备选**：直接做 AI 生成 RPA 流程。
- **判据**：生成层由厂商自己做得更近更好；跨平台运维是真空地带。

### 决策二：根因分析只用 8 条规则，并公开边界

- **决策**：根因分析限定 8 条规则，明确不覆盖上游服务故障（如 API 503）、业务逻辑错误、平台自身 bug。
- **备选**：用 LLM 对运行日志做自由分析。
- **判据**：运维场景中一次错报对信任的摧毁远大于一次漏报。规则的有限性换来每条结论都可解释、可追责——宁可漏报，不可错报。

### 决策三：5 状态模型加入 SILENT（静默）

- **决策**：在常规状态之外增加 SILENT，单独标识「该跑没跑」的流程。
- **备选**：沿用成功 / 失败 / 运行中三态。
- **判据**：静默失败不报错、不打日志，却是业务影响最大的问题；三态模型在结构上无法表达它，必须提升为一等状态。

## AI 的能力边界

产品里有一块专门声明「AI 不覆盖什么」，因为边界声明是信任设计的一部分。

**覆盖（8 条根因规则）**：平台连接中断与鉴权过期 / 元素选择器失效 / 调度冲突与许可位占满 / 执行超时 / 数据格式与编码异常 / 依赖流程未就绪 / 资源不足 / SILENT 静默异常。

**明确不覆盖**：上游服务故障（标记「外部依赖」转人工）、业务逻辑错误（需业务方确认，AI 不替业务下判断）、RPA 平台自身 bug（提厂商工单）。

未命中场景会原样上报原始日志并标注「未命中」，不强行给结论。

## 指标与口径

| 指标 | 数值 | 口径 |
| --- | --- | --- |
| M1 平台适配建议 | 近 8 次接入中推荐与人工选择一致 8 次 | 演示数据 |
| M2 根因分析 | 近 4 次异常中 3 次与人工复盘一致；1 次未命中为上游 503，属明确不覆盖范围 | 演示数据 |
| M3 异常检测 | 近 7 天 3 条告警，人工标注误报 0 条 | 演示数据 |
| M5 成本优化 | 月度净价值 +¥2,100，ROI 14x | 演示数据 |

ROI 口径 =（节省工时 + 避免损失 − 调用成本）/ 调用成本。

## 交互主张

**AI 只给建议，人始终保留最终采纳权。** 四象限里的每条建议都有「采纳 / 驳回」按钮，驳回后该条不再出现——这一点在 `/ai-cockpit` 可以实际操作验证。

## 技术栈

```bash
npx next build --webpack

```
